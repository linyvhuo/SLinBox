# SLinBox 智能工具箱

一款多功能集成工具箱，专为开发、调试、办公自动化场景设计。
集串口调试、自动化工具、截图OCR、数据计算、时序分析、文件工具于一体。

---

## 🧩 功能列表

### 1. 企业微信自动化
- 自动启动企业微信
- 基于 OpenCV 的图标识别与定位
- **图标设置优化**：支持区域截图设置识别图标，自动置顶企业微信窗口
- 自动问答循环执行
- 支持 TXT/CSV 问题库导入与管理

### 2. 截图 + OCR 文字识别
- 全屏/区域截图
- 集成 umi-OCR 快速文字识别
- 支持直线、矩形标注
- 识别结果可导出图片/纯文本

### 3. 串口调试助手
- 串口参数自由配置（波特率、数据位、停止位、校验位）
- ASCII / HEX 模式收发
- 实时日志显示与保存

### 4. 文件工具集
- **文件重命名**：批量文件重命名工具，支持正则表达式和序号命名
- **编码转换**：文件编码格式转换，支持 UTF-8、GBK、ANSI 等多种编码
- **分割合并**：大文件分割与合并，可自定义分割大小和格式
- **文件比较**：文本文件差异对比与可视化，支持行级和字符级对比
- **文件夹比较**：递归比较两个文件夹的差异，生成详细对比报告
- **代码差异查看**：支持语法高亮的代码对比，支持多种编程语言
- **版本控制**：本地项目版本管理，支持版本创建、删除和回滚
- **代码编辑器**：内置带行号显示的代码编辑器，支持语法高亮
- **合并管理**：文件差异合并工具，支持冲突解决

### 5. 进制转换工具
- 支持 2/8/10/16 进制互转
- 输入实时同步转换

### 6. CRC 校验计算
- CRC-8 / CRC-16 / CRC-32
- 支持多种常见多项式

### 7. 时序图绘制
- 信号波形绘制
- 时间轴标注与说明

### 8. 延时计算工具
- 正向计算：时间 → 指令数
- 反向计算：指令数 → 时间

### 9. ASCII 码查询
- 字符 ↔ ASCII 码互转
- 完整 ASCII 对照表

### 10. 数据校验和
- 8 位 / 16 位累加和
- 异或校验和

### 11. 数据手册查询
- 常用元器件手册快速检索
- 支持在线搜索跳转

### 11. 工作日志
- 管理工作日志
- 日志记录功能

### 12. 计划管理
- 计划表管理功能
- **悬浮窗显示**：支持调整窗口大小，优化透明度效果
- 支持计划的新增、编辑、删除和状态管理

## 📁 文件路径说明

- 配置文件：
  ```
  %USERPROFILE%\Documents\SLinBox\config.ini
  ```
- 日志文件：
  ```
  %USERPROFILE%\Documents\SLinBox\logs\
  ```
- 图标模板（企业微信自动化）：
  ```
  %USERPROFILE%\Documents\SLinBox\templates\
  ```
- 版本管理数据：
  ```
  %USERPROFILE%\Documents\SLinBox\versions\
  ```

## ⚠️ 使用注意

1. 首次运行会自动创建配置与日志目录
2. 企业微信自动化需要先设置识别图标（点击"设置"按钮进行区域截图）
3. OCR 功能需安装 umi-OCR 并配置到系统 PATH
4. 串口调试建议使用**管理员权限**运行
5. 加密系统适配：支持在加密环境下的文件操作
6. 本项目仅供学习、研究与内部使用
