# SLinBox 智能工具箱

一款基于 **Qt 5.14.2 + OpenCV** 开发的多功能集成工具箱，专为开发、调试、办公自动化场景设计。
集串口调试、自动化工具、截图OCR、数据计算、时序分析于一体。

---

## 🧩 功能列表

### 1. 企业微信自动化
- 自动启动企业微信
- 基于 OpenCV 的图标识别与定位
- 自动问答循环执行
- 支持 TXT/CSV 问题库导入与管理

### 2. 截图 + OCR 文字识别
- 全屏/区域截图
- 集成 umi-OCR 快速文字识别
- 支持直线、矩形标注
- 识别结果可导出图片/纯文本

### 3. 串口调试助手
- 串口参数自由配置（波特率、数据位、停止位、校验位）
- ASCII / HEX 模式收发
- 实时日志显示与保存

### 4. 进制转换工具
- 支持 2/8/10/16 进制互转
- 输入实时同步转换

### 5. CRC 校验计算
- CRC-8 / CRC-16 / CRC-32
- 支持多种常见多项式

### 6. 时序图绘制
- 信号波形绘制
- 时间轴标注与说明

### 7. 延时计算工具
- 正向计算：时间 → 指令数
- 反向计算：指令数 → 时间

### 8. ASCII 码查询
- 字符 ↔ ASCII 码互转
- 完整 ASCII 对照表

### 9. 数据校验和
- 8 位 / 16 位累加和
- 异或校验和

### 10. 数据手册查询
- 常用元器件手册快速检索
- 支持在线搜索跳转

## 📁 文件路径说明

- 配置文件：
  ```
  %USERPROFILE%\Documents\SLinBox\config.ini
  ```
- 日志文件：
  ```
  %USERPROFILE%\Documents\SLinBox\logs\
  ```
- 图标模板（企业微信自动化）：
  ```
  %USERPROFILE%\Documents\SLinBox\templates\
  ```

---

## ⚠️ 使用注意

1. 首次运行会自动创建配置与日志目录
2. 企业微信自动化需要提前放入图标模板文件
3. OCR 功能需安装 umi-OCR 并配置到系统 PATH
4. 串口调试建议使用**管理员权限**运行
5. 本项目仅供学习、研究与内部使用
